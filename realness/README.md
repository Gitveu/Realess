# Realme Buds T300 Controller (Standalone Prototype)

Автономное Android-приложение на Kotlin + Jetpack Compose для прямого управления наушниками **Realme Buds T300** по протоколу BLE без приложения Realme Link.

---

## Возможности
1. **Чтение батареи (L / Case / R)**: отображение точного процента заряда (0–100%) и индикатора зарядки (`⚡`) для левого, правого наушника и кейса.
2. **Переключение режимов ANC**:
   - «Шумоподавление» (ANC ON)
   - «Выкл.» (ANC OFF)
   - «Прозрачность» (Transparency)
3. **Умный GATT автодетект**:
   - Поддерживает стандартный Nordic UART Service (`6e400001-...`), Airoha BLE (`5052494D-...`) или динамически находит сервисы с флагами WRITE / NOTIFY на любых чипах.
4. **Live-консоль GATT**: прямо на экране приложения отображаются сырые отправляемые и принимаемые кадры протокола.

## Спецификация TL-протокола

### 1. Формат кадра (Wire Frame)
```
[Command: 2 байта LE] [Address: 1 байт = 0x00] [Length: 2 байта LE] [Payload: N байт]
```

### 2. Запрос батареи (Opcode 0x0106)
- **Кадр запроса**: `06 01 00 00 00`
- **Ответ (Opcode 0x8106)**:
  - Байт 0: `0x00` (статус успеха)
  - Байт 1: `Count` (кол-во записей, обычно 3)
  - Далее `Count` записей по 2 байта:
    - Байт 0: `0x01` (Левый), `0x02` (Правый), `0x03` (Кейс)
    - Байт 1: `bits 0..6` — уровень заряда (0..100%), `bit 7` — флаг зарядки (1 = заряжается)

### 3. Переключение ANC (Opcode 0x0404)
- **ANC ON (Шумоподавление)**: `04 04 00 03 00 01 01 08`
- **ANC OFF (Выключено)**: `04 04 00 03 00 01 01 01`
- **Transparency (Прозрачность)**: `04 04 00 03 00 01 01 02`
- **Подтверждение (Opcode 0x8404)**: статус `0x00` в payload.

## Сборка и установка

1. Откройте директорию `BudsT300Controller` в Android Studio (Ladybug или новее).
2. Подключите телефон (Android 8.0+) и нажмите **Run** (`Shift + F10`).
3. В приложении нажмите кнопку **«Выбрать Buds»**, выберите ваши спаренные Realme Buds T300 и нажмите **«Подключить»**.
